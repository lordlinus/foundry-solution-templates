# Evidence rules

Illustrative guideline for a sample template. Not actuarial guidance.

## Pending investigations
When any test that could change a decision is ordered but not reported, the overall decision is Postpone, naming the pending test.

## Unsupported or conflicting values
When the record gives two different values for the same measurement on the same date, use neither. Refer to underwriter and quote both values.

## Low-confidence OCR values
When a decision depends on a value the OCR marked as low confidence, confirm it against the original page before relying on it. If it cannot be confirmed, Refer to underwriter.
